KINGPI WEBSITE STARTER

This is a static prototype for the proposed KingPi community project directory.
Files: index.html, styles.css, app.js

IMPORTANT:
- This is not yet a live Pi Network app and is not an official Pi Network product.
- Pi authentication and Pi payments are not connected.
- Project cards are sample placeholders, not verified fundraisers.
- No donations or payments are collected.
- Do not ask users for Pi wallet passphrases or private keys.

Deploy: upload the ZIP contents (or the unzipped folder) to Netlify's manual deploy area.
The main page must be index.html at the root of the deployed site.
